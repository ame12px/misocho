# misocho（味噌帳）

作家・ライター向けのアイデアストックアプリ。ネタ・着想・メモを手軽に記録・管理できます。

🔗 **デモ**: https://misocho-hdsz.vercel.app

## 使用技術

**フロントエンド**

- React 19 / TypeScript
- Vite
- CSS（デザイントークン・ダークモード対応）

**バックエンド**

- Hono（TypeScript製軽量Webフレームワーク）
- Prisma + SQLite
- JWT認証（bcryptjsでパスワードハッシュ化）
- Vitest（API テスト）

**インフラ**

- フロントエンド: Vercel
- バックエンド: Railway（Persistent Volumeでデータ永続化）

## 機能

- メモの作成・編集・削除（タイトル＋本文）
- タグの追加・削除・絞り込み
- テキスト検索（タイトル・本文）
- スター機能（お気に入り登録・上位表示）
- 作成日時・更新日時の表示
- ダークモード対応
- レスポンシブ対応（PC・スマホ）
- ユーザー認証（メールアドレス＋パスワードでログイン、登録は許可制）
- 削除時の確認ダイアログ

## 設計の工夫

**フロントエンド**

- `useReducer` + `useContext` で状態管理を一元化
- カスタムフック（`useMemos`, `useAuth`）でロジックをコンポーネントから分離
- デザイントークン（CSS変数）で色・サイズを管理し、ダークモードを変数の上書きだけで実現
- 誤操作防止のため、タグ削除・編集ボタンは編集モード時のみ表示
- 環境変数（`VITE_API_URL`）でローカル/本番のAPI先を切り替え

**バックエンド**

- REST API設計（GET/POST/PATCH/DELETE）
- JWTミドルウェアで `/memos` 以下のエンドポイントを保護
- 登録可能なメールアドレスを環境変数で制限（個人・家族利用を想定）
- Prisma + SQLiteでのデータ永続化、Railway Volumeでコンテナ再起動時もデータを保持

## 開発の背景

React・TypeScriptの実践学習を目的に、自分が実際に使いたいツールとして開発。
チュートリアルではなく、実用アプリを育てながら学ぶアプローチをとり、
フロントエンドからバックエンド・認証・デプロイまで一通りの開発フローを経験した。
